# Aplikasi Kopi dan Nyemil (Kiyopon Kopi Nyemil)

Aplikasi mobile pemesanan kopi dan makanan ringan berdasarkan wireframe yang diberikan. Dibuat untuk memenuhi Tugas UTS Pemrograman Mobile.

## Fitur Aplikasi
- **Splash Screen / Welcome**: Halaman awal aplikasi.
- **Sign Up & Login**: Autentikasi pengguna dan penyimpanan sesi.
- **Register**: Pendaftaran akun baru (Nama, Email, Alamat, No Telp).
- **Home**: Menampilkan daftar menu (Makanan, Minuman, Dessert) menggunakan RecyclerView.
- **Keranjang (Order)**: Menambahkan pesanan dengan pop-up jumlah, menampilkan total harga, dan menghapus item.
- **Profile**: Mengedit data user, mengganti foto profil dari galeri, dan Logout.
- **Konfirmasi Pesanan**: Halaman akhir setelah checkout.

## Teknologi yang Digunakan
- **Bahasa**: Kotlin
- **IDE**: Android Studio
- **Komponen**: RecyclerView, SharedPreferences (Penyimpanan Lokal), Activity Result API.

## Cara Menjalankan Aplikasi
1. Clone repository ini: `git clone https://github.com/Naufalt235/kiyoponKopiNyemil.git`
2. Buka project di Android Studio.
3. Tunggu proses Gradle Sync selesai.
4. Jalankan aplikasi pada Emulator atau Perangkat Fisik dengan menekan tombol **Run** (Shift + F10).
